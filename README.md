# Factory Equipment Hierarchy Viewer

Консольний додаток на C# (.NET 8) для отримання та візуалізації ієрархічної структури технічних місць, обладнання та завдань моніторингу заводу у вигляді дерева.

## 📋 Опис завдання

> API повертає інформацію про технічне обладнання та технічне місце на заводі в ієрархічній структурі.
>
> Необхідно реалізувати програму (консольний додаток або WPF) на мові програмування C#, на платформі .NET 8 під операційну систему Windows 10, яка виводить на екран у вигляді дерева (в ієрархічному вигляді) інформацію, отриману по вищевказаному API:
>
> * відображається значення полів `TechnicalPlaces.Name`, `Equipments.Name` та `MonitoringTasks.CharacteristicName`;
> * рівні ієрархії виокремити додатковими відступами від лівого кордону екрану;
> * підрахувати кількість дочірніх елементів дерева та вивести цю кількість в кінці назви відповідного материнського елементу дерева;
> * для реалізації програми створити відповідні класи та методи, дотримуючись принципу Single Responsibility Principle (SRP).

## 🏗 Архітектура проєкту (SRP)

Логіка програми розділена на окремі класи з єдиною зоною відповідальності:

* **`AppSettings`** — централізоване зберігання конфігурації запиту та налаштувань форматування.
* **`TreeNode`** — модель вузла ієрархії, яка зберігає назву, дочірні елементи та обчислює їх кількість.
* **`MonitoringPlanApiClient`** — виконання HTTP POST-запиту (JSON-RPC 2.0) та отримання відповіді від сервера.
* **`JsonTreeBuilder`** — рекурсивний парсинг JSON-відповіді та побудова дерева об'єктів `TreeNode` будь-якої глибини вкладеності.
* **`TreePrinter`** — форматування відступів за рівнями ієрархії та виведення дерева у потік виводу (`TextWriter`).
* **`Program`** — точка входу, ініціалізація залежностей та обробка винятків.

## 🚀 Як запустити

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/kovalenko-olena/plant-equipment-tree.git
   ```

2. Перейдіть у папку репозиторію та запустіть додаток:

   ```bash
   dotnet run --project PpdTreeViewer
   ```

   *(Опціонально можна передати дату першим аргументом: `dotnet run --project PpdTreeViewer -- 2026-10-01`)*
